# Configuraciones

`datasets.json` es el inventario de fuentes y permisos. `data_audit.json` fija fuentes, version, splits, etiquetas declaradas y umbral perceptual para la fase 2. Ninguna configuracion demuestra que los datos existan localmente ni autoriza su descarga.

Las configuraciones futuras de entrenamiento y evaluacion se anadiran en sus fases. Todavia no hay modelos ni parametros de entrenamiento activos.
